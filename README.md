# Compréhension avec Haresh

Marked French reading-comprehension practice for ICSE Grade 10 (46 past-paper passages), by **Learn French with Haresh Sir**, Fravashi Academy, Nashik.

- Click any word for its English meaning; hover underlined words for strategy hints.
- Answers are checked and marked per question; wrong answers get guidance (content, tense, grammar, structure) instead of the model answer.
- "Show me where in the text" draws a bracket round the answer and never lowers the mark.
- A PDF report (marks, answers, attempts, help used) can be downloaded and shared with the teacher on WhatsApp.

## Run / publish
Single self-contained file: `index.html` (jsPDF is loaded from cdnjs). Open it in a browser, or enable **GitHub Pages** (Settings > Pages > Deploy from branch > `main` / root).

Marking is automatic (keywords and grammar rules); the teacher should confirm marks.
